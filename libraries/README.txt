Thư mục này KHÔNG bắt buộc cho việc nạp code.

Việc nạp firmware chỉ cần các file .bin trong thư mục firmware/.
Bạn có thể dùng thư mục này để chia sẻ thêm cho học sinh, ví dụ:
  - mã nguồn Arduino (.ino, .h)
  - thư viện Arduino kèm theo
  - tài liệu hướng dẫn

Nếu không dùng, có thể xóa thư mục này.
